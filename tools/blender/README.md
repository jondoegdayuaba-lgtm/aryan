# Blender asset pipeline

Everything you see in **Night Run** (`/ebike`) — the e-bike and rider, the police cruiser, the
traffic, the buildings, the street furniture, the road tile and every texture — is generated by
the scripts in this folder and exported as glTF (`.glb`) into `ebike/assets/`. There are no
hand-placed or downloaded models. The scripts drive Blender headlessly through the `bpy` Python
module, so you don't need to open the Blender UI.

```sh
python3.11 -m venv .venv && . .venv/bin/activate
pip install -r tools/blender/requirements.txt
python tools/blender/build_assets.py            # everything (~15 s)
python tools/blender/build_assets.py --only bike
```

`--only` takes `city`, `bike` or `vehicles`. Textures are regenerated into a temp folder on every
run (pass `--tex <dir>` to reuse a folder).

| File | What it makes |
| --- | --- |
| `gen_textures.py` | Procedural PBR textures with NumPy + Pillow: four building facades (albedo, emissive lit windows, roughness/metal), shop fronts with signs, wet asphalt with puddle roughness, sidewalk, roof, neon sign atlas, tyre tread |
| `common.py` | Materials (Principled BSDF, glTF-friendly), a UV-aware mesh builder, lathe/tube helpers, GLB export |
| `city.py` | Road/sidewalk/curb tile with lane markings and crosswalks; six building archetypes (glass tower, brick walk-up with fire escape, concrete mid-rise, art-deco, low-rise with billboard, residential with balconies); 16 neon signs; street lights, traffic signals, hydrants, trees, bus shelter, barriers… |
| `bike.py` | Sur-Ron style e-moto: twin-spar frame, gold forks, battery, motor, chain, knobby tyres on 32-spoke wheels, underglow, plus a posed rider with helmet, hoodie and delivery pack |
| `vehicles.py` | Police cruiser (livery, light bar, push bar), sedan, taxi and van. Bodies are lofted from cross-sections, subdivided and cut with boolean wheel arches |
| `preview.py` | Renders a `.glb` with Cycles for a quick look: `python tools/blender/preview.py ebike/assets/ebike.glb out.png 2.6 2.4 1.3 0 0.05 0.8` |

## Conventions the game relies on

* Metres, Z up in Blender. Vehicles and props face Blender **+Y**, which becomes three.js **−Z**.
* Object origins sit on the ground at the footprint centre.
* City tile: 100 m period, 80 m block, 10 m road half-width, four 32 m building lots at (±18, ±18).
  These numbers are mirrored in `ebike/js/config.js`.
* Named nodes the code looks up: `bike_root`, `steer`, `wheel_f`, `wheel_r`, `rider_upper`,
  `car_root`, `wheel_fl/fr/rl/rr`, `ground_tile`, `bld_*`, `neon_00…15`, `prop_*`.
* Materials the code re-tints or flashes at runtime: `paint`, `pl_red`, `pl_blue`, `taillight`.

The sign lettering is baked into textures with DejaVu Sans Bold when it is installed (any bold
sans works; Pillow's built-in font is the fallback).
